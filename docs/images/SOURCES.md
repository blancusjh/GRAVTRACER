# Image sources

`python/grayt/assets/nasa_starmap_4k.jpg` is the 4K celestial-coordinate
JPEG from [NASA Goddard Scientific Visualization Studio's Deep Star Maps](https://svs.gsfc.nasa.gov/3895/)
(visualization by Ernie Wright). Credit: NASA/Goddard Space Flight Center
Scientific Visualization Studio. NASA SVS says its visualizations are
[public domain unless otherwise noted](https://svs.gsfc.nasa.gov/).
The bundled loader reverses the source image's horizontal axis to match
GRAVTRACER's longitude convention. The source image itself is unmodified.

`kerr_disk.png`, `spatial_curvature.png`, and `ray_trajectories_3d.png` are
generated by `examples/readme_figures.py` from the project's rendering code
and the bundled NASA sky map. Disk colors are display mappings. The Flamm
surface is an embedding of a Schwarzschild spatial slice; the Kerr rays use a
pseudo-Cartesian coordinate embedding.
